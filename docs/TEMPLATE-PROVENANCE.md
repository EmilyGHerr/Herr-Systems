# Template provenance

Source: https://github.com/jules-the-ai/herr-systems-templates
Source revision: fcce399 (latest main at conversion).

Styles and original illustrations are reused directly from the source build.
`static/home-services.css` and `static/home-terminal.css` are compiled from the
source's matching SCSS using its package-lock dependencies. Other root CSS/JS
and the assets directory come from the source public directory. Root CSS is
identical unless a documented content/runtime bug requires a change.

Deliberate content changes: removed template instructions, fictional phone
and fictional staff; retained truthful concept-study labels. Terminal replaced
hardcoded/demo replies with Hugo-generated published content. Added pagination
controls appear only when needed. No redesign was requested or applied.
